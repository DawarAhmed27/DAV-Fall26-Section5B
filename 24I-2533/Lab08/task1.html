Step 6: Explain it back

1. Which line keeps only the top 10? The line .slice(0, 10), which runs after the data is sorted from richest to poorest, so it keeps only the first 10 countries.

2. Why do we write d => d.country inside .data(...)? It is a key function that tells D3 to match each bar to its country, so when the year changes the same country's bar slides to its new place instead of a bar being reused for a different country.

3. In 1952, why do the other bars look so short? Kuwait's income (about 108,382) is about seven times higher than the next country, and the x scale goes from 0 to the largest value, so every other bar only fills a small part of the width.
