2. One bar is only about 2 pixels tall because 142 countries are squeezed into a 340 pixel high chart, so the names overlap and cannot be read.

3. After the first fix (keeping only 2007) there are 142 bars, but the chart is still hard to read, so I made the chart taller (18 pixels per country) and sorted the bars from richest to poorest so the order means something.

4. Norway is not in the top 10 if you only use .slice(0, 10), because without sorting it just takes the first 10 rows in alphabetical order (Afghanistan, Albania, Algeria and so on); the missing step is sorting by gdpPercap from highest to lowest before slicing.
